# Security Analyst Journey

## SOC

**SOC (Security Operations Center)** monitors, detects, investigates and responds to security threats.

### SOC Roles

* **L1 Analyst:** Monitor alerts, investigate and escalate.
* **Senior Analyst:** Handle complex investigations.
* **SOC Engineer:** Maintain/configure security tools.
* **SOC Manager:** Manage the SOC team.
* **Incident Responder:** Handle major incidents.

## L1 Analyst Workflow

**Alert → Investigate → Identify threat → Escalate/Contain → Document**

### Common Investigations

* Phishing
* Malware
* Suspicious IPs
* Ransomware
* Unusual logins
* Data theft

## Important Terms

* **IOC:** Evidence of compromise (IP, domain, hash, URL, etc.)
* **True Positive:** Alert is actually malicious.
* **False Positive:** Alert is not actually malicious.
* **SIEM:** Collects and analyzes security logs and generates alerts.

## Room Practical

## Key Takeaway

As a SOC L1 analyst, focus on **alert monitoring, investigation, IOC identification, escalation and documentation**.
